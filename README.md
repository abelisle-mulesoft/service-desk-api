# Brilliant Mule Service Desk API

A simple Spring Boot REST API that simulates an IT service desk.

The API provides operations for managing incidents, including creating, retrieving, updating, assigning, commenting on, resolving, and deleting incidents. The implementation is intentionally lightweight and uses in-memory data rather than a persistent database.

The project is intended primarily for learning and demonstrating API management and agentic API capabilities, including exposing REST API operations as MCP tools using MuleSoft MCP Bridge.

## Technology

* Java 17
* Spring Boot 4
* Maven
